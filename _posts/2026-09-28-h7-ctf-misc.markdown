- overwrite it
- reset the branch

I get part 1 to the flag here.

The zip central directory only lists `readme.txt`. The other files (`part2.txt`, `part3.txt`) exist only as raw local headers so you need to scan the file for `PK\x03\x04` signatures and decompress each one manually:
```python
import struct, zlib

data = open("overexposed.png", "rb").read()
pos = 0

while True:
    pos = data.find(b"PK\x03\x04", pos)
    if pos == -1:
        break

    sig, ver, flags, comp, mtime, mdate, crc, csize, usize, fnlen, extralen = \
        struct.unpack_from("<IHHHHHIIIHH", data, pos)

    name = data[pos+30:pos+30+fnlen].decode()
    start = pos + 30 + fnlen + extralen
    blob = data[start:start+csize]

    if comp == 8:
        out = zlib.decompress(blob, -15)
    else:
        out = blob

    print(f"{name}: {out.decode()}")
    pos = start + csize
```
